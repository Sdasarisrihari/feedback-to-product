# Demo script (≈6 min)

1. **Overview** (signed out): synthetic Trellis feedback, volume, sentiment, urgent issues. Sidebar shows "Demo · saved in this browser only".
2. **Feedback Explorer**: filter by source; show a flagged duplicate and a flagged instruction-like record ("treated as data").
3. **Insights → Run AI analysis**: AI themes with *verified* quotes; note the demo-mode provenance line and rejected citations.
4. **Prioritization**: change a weight; ranking rationale updates.
5. **Knowledge Base**: ask "Does the documentation confirm offline mode on mobile?" — documented vs. unverified verdicts.
6. **PRD Studio**: generate a PRD; show requirements downgraded to "needs validation"; edit → revision 2.
7. **Sign in**: accept the one-time browser import; "All changes saved"; reload — data restored; provenance now "checked on the server".
8. **Human Review**: score the PRD; summary only counts completed reviews.
9. **Task Review**: approve/reject draft tasks — nothing leaves the app.
